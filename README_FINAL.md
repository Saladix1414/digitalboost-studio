# DigitalBoost — versión final

Flujo principal:

Boot → Splash → Presentación → Comenzar gratis → Página principal → Entorno de herramienta

La página principal usa como referencia visual la composición aprobada: navbar, hero con dragón, estadísticas, cinco herramientas, sección IA, integraciones, CTA y footer.

Se eliminó del flujo la pantalla “¿Qué quieres crear hoy?” y se eliminó el botón “Explorar herramientas” de la presentación y de la página principal.

## Ejecutar

```bash
npm run dev
```

El proyecto conserva `node_modules` del entorno de origen para evitar reinstalaciones innecesarias en el mismo dispositivo. Si se mueve a otra plataforma/arquitectura, puede ser necesario reinstalar dependencias.
