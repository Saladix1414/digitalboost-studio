# DigitalBoost — Glosario

Estado: CANÓNICO
Autoridad: Secundaria
Documento raíz: ../agente.md

---

## DigitalBoost

Ecosistema tecnológico compuesto por seis productos principales.

## Commerce OS

Plataforma de comercio digital y operación de negocios.

## Store Builder

Módulo de Commerce OS para construcción y gestión de tiendas.

## Web Builder

Constructor independiente de experiencias web.

## AI Forge

Plataforma para construir, probar, evaluar, desplegar y gobernar
sistemas de inteligencia artificial.

## Trading Islands

Producto especializado en mercados, estrategias, simulación, bots,
riesgo y activos digitales.

## Sentinel

Plataforma de ciberseguridad y pentesting ético autorizado.

## Nexus

Foro y capa comunitaria del ecosistema DigitalBoost.

## PULSE

Inteligencia operacional perteneciente actualmente a Commerce OS.

No constituye actualmente una infraestructura global del ecosistema.

## Command Center

Interfaz de comandos agéntica de AI Forge.

## Agent

Sistema de IA orientado a objetivos y capaz de utilizar capacidades y
herramientas autorizadas.

## Workflow

Secuencia o grafo de operaciones.

## Tool

Capacidad ejecutable que un sistema autorizado puede utilizar.

## Skill

Paquete de conocimiento procedimental e instrucciones especializadas.

## Knowledge

Información que un sistema puede consultar.

## Memory

Información que un sistema puede conservar.

## Model

Proveedor o motor de inferencia.

## Sandbox

Entorno restringido para ejecución segura.

## Evaluation

Mecanismo para medir calidad y comportamiento.

## Trace

Registro estructurado de una ejecución.

## Checkpoint

Estado recuperable de un sistema.

## Executor

Capa autorizada para ejecutar acciones permitidas.
