# DigitalBoost — Glosario

Estado: CANÓNICO

---

## DigitalBoost

Ecosistema general.

## Commerce OS

Plataforma de comercio digital.

## Store Builder

Módulo de Commerce OS para construcción y gestión de tiendas.

## Web Builder

Constructor independiente de sitios web.

## Sentinel

Plataforma de ciberseguridad y pentesting ético.

## AI Forge

Plataforma para construir, probar, evaluar, desplegar y gobernar sistemas de IA.

## Command Center

Interfaz de comandos agéntica de AI Forge.

## Agent

Sistema de IA orientado a objetivos y capaz de utilizar capacidades y herramientas autorizadas.

## Workflow

Secuencia o grafo de operaciones.

## Tool

Capacidad ejecutable que un agente puede utilizar.

## Skill

Paquete de conocimiento procedimental e instrucciones especializadas.

## Knowledge

Información que el sistema puede consultar.

## Memory

Información que el sistema puede conservar.

## Model

Proveedor o motor de inferencia.

## Sandbox

Entorno restringido para ejecución segura.

## Evaluation

Mecanismo para medir calidad y comportamiento.

## Trace

Registro estructurado de una ejecución.

## Checkpoint

Estado recuperable de un sistema.

## PULSE

Capa agéntica de DigitalBoost que convierte intención e inferencia en solicitudes operacionales.

## Executor

Capa autorizada para ejecutar acciones permitidas.

## Nexus

Plataforma comunitaria y de conocimiento.
