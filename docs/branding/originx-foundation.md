# OriginX Foundation — visible brand migration

Scope: visible application copy, accessible labels, built-in template credits,
new-project default names, browser/share metadata and an OX SVG favicon.
Product names (Commerce OS, PULSE, Brain Boost, Trading Islands, Sky Workshop)
remain unchanged. Existing dragon/island artwork is preserved.

Compatibility: keep module/file names, imports, CSS selectors, API routes,
provider environment names, tenant IDs, database schemas, localStorage and
IndexedDB keys unchanged. Existing authored project text is not rewritten.
Historical snapshots and backups retain the old name. Repository, hosting
service names and domains are separate account settings, not changed here.

Validation: production build and Websites Builder regression suite.
Mobile visual acceptance is still required on the deployed preview.
