## Principios

La accesibilidad se considera desde el diseño.

Verificar:

- contraste;
- foco;
- teclado;
- labels;
- semántica;
- navegación;
- estados;
- errores;
- tamaños táctiles;
- lectores de pantalla cuando corresponda.

---

## AI Forge

El Command Center debe incluir:

- feedback visual claro;
- estados de ejecución;
- mensajes legibles;
- distinción visual y textual entre éxito, warning y error;
- navegación accesible;
- comandos comprensibles.

El usuario no debe depender únicamente del color para comprender el estado.
