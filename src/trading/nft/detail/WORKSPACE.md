# NFT Detail Workspace

Phase 28B introduces the product-facing NFT Detail workspace.

## Local navigation

Marketplace catalog:

View Asset

 local listing selection

 detail lookup

 NFT Detail workspace

 Back to Marketplace

No router, wallet, network or blockchain dependency is required.

## Detail surfaces

The workspace exposes:

- identity
- collection
- creator reference
- DNA reference
- provenance reference
- seller reference
- wallet reference
- price
- currency
- sale type
- listing status
- local detail validation

## Execution boundary

Buy Asset remains disabled.

Verify On-chain remains disabled.

Phase 28 does not perform:

- payment
- wallet signing
- DBX debit
- token transfer
- contract execution
- blockchain verification

All displayed records remain non-authoritative.

Phase 30 owns blockchain execution.
