# Marketplace Eligibility

Phase 26B introduces listing eligibility and sale intent.

Eligibility is evaluated before publication.

Checks include:

- marketplace listing validity
- READY status
- provenance reference presence
- DNA reference presence
- seller reference
- wallet reference identifier
- positive price
- valid expiration
- valid provenance closure
- asset alignment
- collection alignment

## Sale intent

A sale intent represents an internally modeled request to publish a listing.

It is not:

- wallet approval
- blockchain signature
- marketplace settlement
- payment execution
- ownership proof
- legal title transfer

## Authority boundary

Eligibility means only that the local domain requirements are satisfied.

Eligibility does not mean:

- seller owns the NFT
- sale is on-chain
- settlement is final
- payment happened
- provenance is absolute truth

All results remain:

`authoritative:false`
