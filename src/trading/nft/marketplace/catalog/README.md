# NFT Marketplace Catalog

Phase 27 introduces the product-facing marketplace catalog.

The catalog operates only on local marketplace listings.

## Discovery capabilities

- text search
- sale type filter
- currency filter
- collection filter
- minimum price
- maximum price
- newest sorting
- ascending price
- descending price

Only LISTED records may appear in discovery.

## Important boundary

Catalog visibility does not mean:

- on-chain availability
- seller ownership proof
- reserved inventory
- settled payment
- executable transaction
- blockchain finality

Catalog output remains:

`authoritative:false`

Real execution is still owned by Phase 30 — Blockchain Gateway.
