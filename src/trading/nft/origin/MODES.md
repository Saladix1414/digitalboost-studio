# NFT Origin Modes

Origin supports four creation modes.

## CLASSIC

Manual or Forge-based creation.

## GENERATIVE

Creation based on:

- generator reference
- deterministic seed
- deterministic ruleset
- ruleset version

Generative configuration describes the creation method only.

## LIVING

Creation designed for later state evolution.

Living Origin records:

- evolution model
- initial state
- evolution schema reference

It does not authorize future state changes by itself.

## IMPORTED

Creation context captured from an external source.

Imported Origin records:

- source system
- external asset reference
- import timestamp

Importing an asset does not prove authorship or provenance.

## Authority Boundary

Origin mode configuration never establishes:

- provenance
- ownership
- authenticity
- blockchain finality
- governance authority
