# Origin ↔ DNA Consistency Bridge

The bridge validates consistency between Origin and NFT DNA.

It checks:

- asset identity
- collection identity
- creator identity
- version sanity
- forge configuration integrity
- creation timestamps

The bridge does not merge the domains.

It does not establish:

- provenance
- ownership
- authorship authority
- blockchain finality
- legal authenticity

A consistent bridge means only that the recorded Origin context agrees with the current DNA model.
