# NFT Origin

Origin captures how an asset came into existence.

It records:

- asset identity
- collection identity
- creator reference
- creation mode
- creation timestamp
- forge configuration
- source reference
- origin version
- origin lifecycle state

Origin does not establish:

- provenance
- ownership history
- legal authenticity
- blockchain finality
- governance authority

Origin is creation context only.

Provenance belongs to a later phase.
Blockchain proof remains part of the DNA / mint evidence model.
