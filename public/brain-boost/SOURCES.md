# Neural Arcade — asset sources and reuse notes

## Original visual assets
The WebP card illustrations in `assets/` were generated as original game concept art for this project. Orca and seagull artwork is reserved for later expansions and is not included in the initial playable set.

## Real animal audio — Ocean Echoes
The initial game uses three official animal audio clips published by NOAA Fisheries:

- Bottlenose dolphin: https://www.fisheries.noaa.gov/s3/2023-04/Tutr-multisound-NOAA-PAGroup-03-bottlenose-dolphin-clip.mp3
- Humpback whale: https://www.fisheries.noaa.gov/s3/2023-04/Meno-song-NOAA-PAGroup-13-humpback-clip.mp3
- Atlantic spotted dolphin: https://www.fisheries.noaa.gov/s3/2023-04/Stfr-Multisound-NOAA-PAGroup-01-atlantic-spotted-dolphin-clip.mp3
- Source page: https://www.fisheries.noaa.gov/national/science-data/sounds-ocean-mammals
- NOAA audio policy: https://sos.noaa.gov/copyright/

NOAA's published policy states that audio recordings created by NOAA generally may be downloaded, excerpted, reproduced and distributed without further permission, except that third-party narration, music, or other copyrighted material may need separate permission. This project uses species-specific clips published on NOAA Fisheries' own animal-sounds page and includes a source credit in the UI. Review the source page and policy before any commercial release; do not imply NOAA endorses DigitalBoost.

The installer attempts to download local MP3 copies. If network retrieval fails, the game falls back to the official source URLs, if the browser can reach them.

## Origin X visual note
The four dragon images are original concept art for the Origin X-themed prototype, not verified canonical Origin X character assets. They can be replaced with the project's official dragon art when those assets are supplied.
